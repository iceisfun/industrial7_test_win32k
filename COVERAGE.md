# Syscall coverage

1316 syscalls (win32u service table).

Two levels of evidence, from strongest to weakest:

1. **Direct**: a test names the `Nt*` stub (a `win32u.dll` export) in a real call context and invokes it.
2. **Witnessed kernel entry**: the syscall was observed executing during a run on Windows 10. This level is **not
   measured** in this tree (no run records which service numbers were entered), so no count is claimed for it. Caveat
   when it is measured: most gdi32 drawing and attribute calls are batched in user mode in the GDI batch of the
   thread (`GdiFlush` or a full batch sends them); a call through gdi32 can therefore return before any kernel entry
   happens, so it counts as witnessed only after a `GdiFlush` (or a call that forces a flush) in the same test.
